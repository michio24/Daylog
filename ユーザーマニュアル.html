Daylogとは

Daylogは、毎日の予定・出来事・メモ・振り返りを、日付ごとにまとめて残すWindows用の日記アプリです。

✓

基本は「書くだけ」で大丈夫

入力した内容は自動的に保存されます。日記を外部サービスへ送信しないため、インターネットにつながっていないときも基本機能を使えます。

このマニュアルで使う言葉 「クリック」は、マウスの左ボタンを1回押す操作です。「入力欄」は、文字を打ち込める四角い場所です。

はじめに

Daylogを開く
Daylog.exeをダブルクリックします。
「今日」を確認
起動すると、今日の日付の画面が表示されます。
1つ書いてみる
「タスクを追加」に、今日やることを入力します。

入力したらキーボードの Enter を押してください。追加されたタスクが画面に表示されれば、最初の操作は完了です。

「WindowsによってPCが保護されました」と表示された場合 配布元が信頼できることを確認してから操作してください。出所がわからないファイルは開かないでください。

画面の見方

画面上部の名前をクリックすると、4つの画面を切り替えられます。

図は画面の位置関係を簡略化したものです。

今日今日の予定と記録を書く
履歴カレンダーから過去を見る
検索言葉を使って記録を探す
設定AIやバックアップを設定する

見やすさを変える

画面右上の 1カラム 2カラム 3カラム で並び方を変更できます。最初は、上下に順番に表示される「1カラム」がおすすめです。丸い色のボタンから配色も変更できます。

一日の流れ

すべて埋める必要はありません。その日に必要なところだけ使えます。

1
朝・仕事を始める前

今日やることを決める

  1. 上部の 今日 をクリックします。
  2. 「今日やること」の タスクを追加 に予定を入力します。
  3. Enter を押して追加します。予定が複数あれば繰り返します。
入力例： 10時までに見積書を確認する

終わった予定は、左側の丸い印をクリックします。チェックが付き、完了した数が「1 / 3」のように表示されます。

登録した予定は、左端のつまみをドラッグして順番を変えられます。鉛筆マークをクリックすると、名前の修正と期限の設定・解除ができます。期限を過ぎた未完了の予定には 🔥 が表示されます。

2
日中・何かあったとき

出来事を短く記録する

  1. 「今日の記録」の「今あったことを書く…」をクリックします。
  2. 出来事や気づきを入力します。
  3. 必要なら 仕事 体調 などの種類を選びます。
  4. Ctrl を押しながら Enter を押して登録します。
入力例： 14:00 お客様から了承の連絡。明日発送する。

時刻は自動で付きます。登録後の種類は、記録の横にあるタグをクリックすると変更できます。

3
考えを整理したいとき

詳しい内容をメモに書く

  1. 「今日のメモ」の ＋ メモを追加 をクリックします。
  2. 上の欄にタイトル、下の広い欄に本文を入力します。
  3. 書き終えたら「保存済み」を確認し、閉じる をクリックします。

長い文章、会議メモ、画像や資料をまとめたいときに便利です。詳しくは「メモの使い方」をご覧ください。

4
夜・仕事や一日の終わり

今日を振り返る

「今日を振り返る」に、次の3項目を入力します。短い一言だけでも十分です。

  • 今日よかったこと：うまくいったこと
  • うまくいかなかったこと：困ったことや改善したいこと
  • 明日に持ち越すこと：明日の自分への申し送り
入力例： 見積書を早めに確認できた／午後は集中が切れた／発送準備を明日の最初に行う
5
最後の操作

一日を完了する

  1. 入力欄の下に「保存済み」と表示されていることを確認します。
  2. 今日を完了 をクリックします。

完了後は内容が書き換わらない状態になります。修正したい場合は、画面上部の 再編集 をクリックしてください。

「今日を完了」は必須ではありません まだ書き足す予定がある場合は、完了せずにDaylogを閉じても構いません。入力済みの内容は保存されます。

これだけ覚えれば使えます

  • 朝：「今日やること」を書く
  • 日中：「今日の記録」に短く残す
  • 夜：「今日を振り返る」を書く

メモの使い方

文字を読みやすく整える

メモ編集画面の上部には、見出し・太字・箇条書き・チェックリストなどのボタンがあります。整えたい文字をマウスで選び、使いたいボタンをクリックします。表示 をクリックすると、仕上がりを確認できます。

画像やファイルを付ける

  1. 画像なら 画像、その他の資料なら 添付 をクリックします。
  2. 表示された画面でファイルを選び、開きます。
  3. 表示 に切り替えて、正しく追加されたか確認します。

ファイルを本文へドラッグして置く方法や、コピーした画像を貼り付ける方法も使えます。

削除は元に戻せません タスクや記録の「×」、メモの「メモを削除」を押す前に、消してよい内容か確認してください。

別のファイルとして残す

メモ画面または一日の振り返りにある Markdownで保存 をクリックすると、保存場所を選び、一般的なテキストファイル（.md）として書き出せます。添付ファイルがある場合は一緒に書き出されます。

過去の記録を見る・探す

日付から探す
  1. 上部の 履歴 をクリックします。
  2. カレンダーの日付をクリックします。
  3. 右側の内容を確認します。編集する場合は「この日を開く」をクリックします。
色が濃い日ほど、記録が多くあります。
言葉から探す
  1. 上部の 検索 をクリックします。
  2. 探したい言葉を入力します。
  3. 表示された結果をクリックすると、その日の画面が開きます。
タスク・記録・メモ・振り返りをまとめて検索します。

前の日・次の日を開く

「今日」画面の日付の左右にある ‹ と › をクリックします。3カラム表示では、左側のカレンダーから日付を選ぶこともできます。

設定とバックアップ

大切な記録をバックアップする

Daylogは起動時に1日1回、自動でバックアップを作ります。すぐに作りたい場合は、上部の 設定 →「バックアップ」の 今すぐ作成 をクリックします。「作成しました」と保存場所が表示されたら完了です。

おすすめ パソコンの故障に備え、Daylogのフォルダー自体も、定期的にUSBメモリーなど別の場所へコピーしてください。

AIによるまとめ（必要な方だけ）

AI機能は最初はオフです。利用には、対応するAIプログラムとモデルファイルの準備が必要です。設定済みの場合は、振り返り画面の AIで今日をまとめる から実行できます。

AIが提案した「明日への候補」は、＋ 明日のタスクへ をクリックすると翌日の予定に追加されます。AIを使わなくても、日記の基本機能はすべて利用できます。

祝日を更新する

設定 →「祝日データ」の 公式データから更新 をクリックします。この操作のときだけ、内閣府のWebサイトへ接続します。

便利なキー操作

慣れるまでは使わなくても問題ありません。Ctrl を押したまま、もう一方のキーを1回押します。

キーできること
Ctrl + Tタスク入力欄へ移動
Ctrl + Enter「今日の記録」を登録
Ctrl + M今日のメモへ移動
Ctrl + R振り返りへ移動
Ctrl + F検索画面を開く
Ctrl + S現在の入力を確定する

困ったとき

文字を入力できません
その日が「完了済み」になっていないか確認します。完了済みの場合は、画面上部の「再編集」をクリックしてください。
入力した内容が心配です
メモや振り返りでは「保存済み」の表示を確認してください。エラーが表示された場合は、Daylogを閉じず、表示された文面を控えてください。
今日以外の日付を開きました
上部の「今日」をクリックします。今日の日付の画面へ戻ります。
画面が狭くて見づらいです
画面右上で「1カラム」を選び、Daylogのウィンドウを大きくしてください。
AIのボタンがありません
AIは任意機能です。「設定」でローカルAIを有効にし、正しいモデルファイルを指定した場合だけ利用できます。
アプリを閉じても大丈夫ですか
通常はそのまま閉じて構いません。終了前に入力内容が保存されます。保存エラーが表示されているときは閉じないでください。
